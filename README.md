# Or-nithines
## ダイスバトル（`dice-battle/`）

CPU と 1 対 1 で 6 面ダイスの合計を競うブラウザゲーム。`dice-battle/index.html` をブラウザで開くだけで遊べます（ビルド不要）。

### ルール
1. ゲーム開始時、プレイヤーと CPU の 1 個目のダイスが自動で振られる
2. プレイヤーは「ロール」（追加で振る）か「ステイ」（確定）を選ぶ
3. 合計が 16 以上になると「バースト」となり 0 点
4. 合計 15 以内で高い方が勝ち。同点は引き分け

### 補足仕様
- 手番はプレイヤー → CPU の順。プレイヤーがバーストした時点でプレイヤーの手番は終了
- CPU は合計 12 未満なら振り続け、12 以上でステイ（`game.js` の `CPU_STAY_AT` で調整可）
- 勝敗数はページを開いている間カウント
